# Report Generation Web App

A powerful and user-friendly web application designed to streamline the creation, management, and exporting of project reports.

## Features

- **Project Details Management:** Easily input and manage core project information, including Client, Facilities Management, Location, Job Codes, and fixed temporal data (Month/Year).
- **Dynamic Report Sections:** Customize your report with toggleable sections such as Annual Plan, Operations, PPM, Reactive Tasks, HSE, and more.
- **Predefined Contacts:** Quickly assign reporting roles using a built-in, customizable list of predefined contacts (e.g., Operations Coordinators, Project Engineers).
- **Bulk Photo Uploads:** Effortlessly attach multiple photographs for different locations via an intuitive drag-and-drop interface. Full support for bulk selecting JPG and PNG files.
- **Smart Data Extraction:** Upload existing reports to automatically extract and populate data fields, saving time on manual data entry.
- **Export Capabilities:** Generate professional, formatted reports instantly in **Word** or **Excel** formats with a single click.

## Usage

1. Open `index.html` in any modern web browser (Google Chrome or Microsoft Edge recommended).
2. Fill in the **Project Details** at the top of the page.
3. Toggle the specific sections you want to include in your final report.
4. For the **Photographs** section, you can add location headings and upload multiple photos at once by clicking the upload zone or dragging and dropping your files directly into the box.
5. Review the live preview of your report directly in the browser.
6. Use the **Export to Word** or **Export to Excel** buttons at the bottom of the page to download your final document.

## Local Setup

This application is entirely client-side, built using standard HTML, CSS, and JavaScript. No complex build tools, dependencies, or backend servers are required.

- Simply clone or download the repository.
- Open `index.html` in your browser to start using the app instantly.
